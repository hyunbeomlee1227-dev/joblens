# Keep resume analysis ephemeral

JobLens does not retain a Candidate's full Sanitized Resume for future recommendations or persist deep Analysis Results for later retrieval. Approved resume content exists only while recommendation or analysis work is in progress; a deep Analysis Result is available only in the current session. A later analysis requires another Extraction Review and submission. Temporary resume content is deleted when work succeeds, fails, or is cancelled; abandoned work receives a short automatic expiry so a crashed worker cannot retain it indefinitely. Recommendation History is an explicit, narrower exception: it persists selected reasons and approved Resume excerpts as described in ADR-0011, and therefore remains sensitive Candidate data. The exact temporary expiry duration is an operational setting to verify in testing.
