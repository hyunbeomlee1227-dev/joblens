# Use Amazon Bedrock for evidence explanations

JobLens will use Amazon Bedrock for AI-generated Requirement Evidence and Evidence Gap explanations after the Candidate approves the Sanitized Resume and is told that this text will be sent to AWS. The original Resume document remains in the browser, and deterministic Job Listing eligibility stays in code. Real Candidate content is sent only to a model and API that support zero data retention in the Seoul (`ap-northeast-2`) Region without cross-Region inference; if no suitable option is available, AI analysis remains unavailable rather than silently changing retention or processing location. The account or project retention mode must be set to `none` and verified for the selected model; `store=false` alone is not sufficient for all models. Per-Candidate limits and an analysis kill switch constrain cost. [AWS data retention](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html), [cross-Region inference](https://docs.aws.amazon.com/bedrock/latest/userguide/cross-region-inference.html)
