# Run the public shell on Seoul EC2 behind CloudFront

JobLens deploys its first always-available Next.js container to one small EC2 instance in Seoul behind a CloudFront HTTPS endpoint, with images in ECR and deployments performed through Systems Manager using GitHub OIDC. App Runner was rejected because it is unavailable in Seoul and stopped accepting new customers on 2026-03-31; ECS with an Application Load Balancer was rejected for the first fixture release because its idle cost is disproportionate to the workload. This choice keeps later BFF processing in the intended Seoul region and demonstrates container deployment, least-privilege administration, observability, cost alerts, health checks, and rollback, while deliberately accepting a single-instance availability limit until real traffic justifies a multi-instance runtime.
